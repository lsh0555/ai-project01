## 2. 프로젝트 목표
1. GitHub 팀 저장소를 만들고 팀원을 Collaborator로 등록할 수 있다.

2. 작업을 기능 단위로 나누어 Issue로 관리할 수 있다.

3. 최신 main 브랜치에서 개인 작업 브랜치를 생성할 수 있다.

4. AI에 기능 단위의 구체적인 요청을 작성할 수 있다.

5. AI가 생성한 코드를 작은 단위로 나누어 실행할 수 있다.

6. 실행 전 예상 결과와 실제 결과를 비교할 수 있다.

7. 정상 조건과 예외 조건을 사용해 코드 결과를 검증할 수 있다.

8. AI 생성 코드를 실제 데이터 구조와 프로젝트 환경에 맞게 수정할 수 있다.

9. 변경 내용을 의미 있는 단위로 Commit하고 Push할 수 있다.

10. Pull Request에 작업 목적, 변경 내용, 실행 방법, 검증 결과를 작성할 수 있다.

11. 다른 팀원의 PR을 직접 실행하고 리뷰할 수 있다.

12. 리뷰 결과를 코드에 반영한 뒤 main 브랜치에 Merge할 수 있다.

13. pandas를 활용하여 여러 CSV 파일을 연결하고 지표를 계산할 수 있다.

14. Jupyter Notebook에 목적, 코드, 결과, 검증, 해석을 기록할 수 있다.

15. Streamlit에 지표, 필터, 표, 차트를 구현할 수 있다.

16. README만 보고 다른 사람이 프로젝트를 설치하고 실행할 수 있도록 문서화할 수 있다.

17. 프로젝트에서 배우거나 이해하지 못한 내용을 회고하고 발표할 수 있다.
